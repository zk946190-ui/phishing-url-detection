# AI-Based Phishing URL Detection

A Python machine-learning workflow that classifies URLs as phishing or legitimate.

## Tech stack
Python, Pandas, Scikit-learn, TF-IDF Vectorizer, Random Forest

## Approach
1. Loaded and cleaned the URL dataset with Pandas
2. Converted URLs to features using TF-IDF
3. Trained a Random Forest classifier

## How to run
1. Install the requirements: pip install pandas scikit-learn
2. Run files
